# M2 · 壳层、首页与案件列表

> 日期：2026-11-19  
> 分支：`feat/visual-refactor-m1`  
> 状态：已完成  
> 依据：`DESIGN.md`、`docs/redesign/refactor-plan-v2.md`

## 1. 本轮范围

把 B「工人夜校读本」骨架落到站点壳层、首页和案件列表：

- 顶部站点头、底部来源与免责声明。
- 读本式首页：范围说明、主标题、两个入口、信任事实、产出说明、四步路径、边界说明。
- 我的案件：空状态与案件行；信息完整度、下一步、继续/删除。
- 案件工作台壳层：返回入口、案件标题、演示标记、双进度、四个标签页、移动端底部导航。

本轮**没有**迁移对话、案件分析、行动步骤、填报参考的页面内容，也**没有**改后端接口、Agent 行为与法律内容。
