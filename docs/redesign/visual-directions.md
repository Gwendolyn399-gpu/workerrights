## 2. 三套方向

### 方向 A · 案卷档案袋

**一句话**：把案件当成一份会被核对、带走、提交的案卷。

- **世界**：牛皮纸案卷、文件夹页签、校对章、衬线标题。
- **颜色**：暖纸 `#f2eee4`、陶土 `#a34f2d`、鼠尾草 `#496354`、墨 `#22231f`。
- **签名动作**：结论/证据/依据的页签 + “已核对”章；让三块内容像同一份卷宗的不同页。
- **最强处**：专业、可信、像“真的在整理材料”，适合承载事实档案与法律依据。
- **风险**：容易偏档案馆/旧式公文；移动端正文密度需要控制。

### 方向 B · 工人夜校读本

**一句话**：把法律整理变成工人夜校的一页读本。

- **世界**：廉价新闻纸、粗黑标题、红色批注、放大的课时编号。
- **颜色**：新闻纸 `#f4efe2`、信号红 `#c23b2a`、墨黑 `#171717`、绿 `#2e6b4f`。
- **签名动作**：每条结论像一课的“要点”；红色只给当前问题、风险和下一步。
- **最强处**：低读写门槛、手机强光下可读、最像“工友能看懂的读本”；390px 首屏仍先给结论。
- **风险**：要避免儿童教材感或说教；必须保持成人语气、真实材料，不做卡通插画。

### 方向 C · 办理路线图

**一句话**：把办理路径画成一张路线图。

- **世界**：深海军蓝外壳、瓷白站点、珊瑚色当前站、线路色区分渠道。
- **颜色**：海军蓝 `#122e3a`、线路蓝 `#2e6f8e`、珊瑚 `#c54b31`、浅灰绿 `#f1f4f3`。
- **签名动作**：结论和行动步骤是一条有站点的路线；当前站最亮，已完成站留下痕迹。
- **最强处**：把“被推来推去”的流程变成可理解的路径，尤其适合行动步骤页。
- **风险**：路线图有学习成本，容易像交通 App；不能盖过“大白话”和证据整理。

### 定稿组合 · 工人读本 × 案卷事实 × 办理路线

用户已确认：**B 为主方向，吸收 A 和 C 的局部语法。**

- **主骨架**：B 的新闻纸、粗黑标题、红色当前标记和“一课一件事”的版面节奏。
- **吸收 A**：案件档案的“事实 / 法律依据”页签、“已核对”章和案卷式事实面板。
- **吸收 C**：只在行动步骤页使用“现在 / 下一步 / 之后”的路线站点，不把分析页交通图化。
- **边界**：B 是默认语言，A 和 C 是局部语法；三者不能在同一屏争夺主视觉。

完整概念稿：[04-hybrid.html](directions/04-hybrid.html)

## 4. 已确认方案

**B · 工人夜校读本为主，吸收 A 的事实档案与 C 的行动路线。**

理由：

- 目标用户可能年龄偏大、法律术语不熟，B 的字号和对比度最适合工地/宿舍场景。
- 390px 首屏仍能先给结论，不把“下一步”埋在后面。
- 它把“一次只问一个问题”从交互原则变成了可见的版面节奏。
- 最容易在首页、对话、行动步骤、填报参考之间保持一致，而不需要每页重新解释视觉。

但不丢掉 A 和 C 的长处：

- **借 A 的“案件档案 / 已核对章 / 页签”** 作为事实面板的结构，让事实有“可核对”的重量。
- **借 C 的“当前站 / 下一步”** 只用在行动步骤页，把 8 步变成可理解的路径，不把整个产品交通图化。

A 和 C 的完整方向保留为备选，不进入正式实现；它们的局部语法已并入定稿组合。

## 5. 共同约束

无论选哪套，以下不变：

- 不自动登录或提交政府平台。
- 不要求身份证号、银行卡号、证件照。
- 不承诺追回工资或胜诉。
- 法条和渠道必须有来源与核验状态。
- 事实只有一个源；信息完整度与办理进度分开。
- 移动端正文不小于 16px，关键触控目标不小于 44px。
- 当前蓝色工具感保留为安全基线，不作为第四个新方向。
